# 资源

## Logo

官方图形源文件见 [`logo/`](logo/)。应用图标与界面标志已接入 Xcode 资源目录，不要另做一套。

## 情绪贴纸

源文件见 [`emotion-stickers/`](emotion-stickers/)。独立小团子角色，只用于情绪页、今日情绪卡和手表情绪页。

## 界面截图

仓库不提交生成的 PNG 截图。先运行 `python3 prototype/build.py`，再执行 `python3 tests/browser_test.py`，截图会写入本目录；文档渲染器使用 `desktop-overview.png`。原始截图和 Word 导出版另存于已交付的完整设计包。所有界面数据均为合成示例，不是实机健康记录。
