# watch you

**AI 健康与情绪助手 · iPhone + Apple Watch · v2.0 设计与原型包**

项目仓库：`Yurken/watchYou`。产品名称统一写为 **watch you**。

当前交付是完整产品需求、可交互的浏览器原型、测试与原生开发交接材料。**不是已签名 App、完成的 Xcode 工程或经过医学验证的情绪识别产品。** 所有健康数值均为合成示例。

## 本版变化

情绪从主动打卡改为 AI 自动推断流程，包含状态、时间线、依据、未知状态和可选纠正；界面不突出设备数量，数据来源只在详情与设置出现；AI 覆盖今日、睡眠、心率、恢复、运动、习惯、趋势与问答。设置支持自定义 URL、Model、密钥、协议、多组服务、调用参数、数据范围和功能开关。

## 先体验

用本机浏览器打开 `prototype/index.html`。这是单文件页面，无运行时依赖、远程字体或 CDN，默认离线演示，不需要密钥。桌面显示手机与一块手表的界面；窄屏自动调整布局。顶部可切换完整示例、基线不足、无可读数据和历史缓存。

建议体验顺序：今日 → AI 情绪 → 为什么这样判断 → 睡眠/恢复 → AI 助手 → 设置 → AI 服务。数据来源在设置或指标详情中进入。

手机与手表中的习惯记录、断连与恢复、来源切换、呼吸计时、备份恢复均为可操作演示；不会操作真实设备或系统通知。

## 配置真实模型请求

进入“设置 → AI 服务”，填入自己的完整 Base URL、Model 与认证方式，按服务需要选择 Chat Completions、Responses 或 Messages。URL 由用户定义，原型不预设可用模型。保存不发送健康数据；模型列表与连接测试分别确认接收端，连接测试不含健康摘要。

切换为“真实 AI”后，首次分析会展示目的地、模型和待发送摘要。只有明确确认才发送。**即使调用真实模型，输入仍是模拟健康数据，不是 HealthKit 数据。** 原型不会使用真实健康数据测试推断准确性。

密钥仅放在当前网页内存，不写入 localStorage、备份或源码；刷新后需重填。更换地址/认证会清除原密钥绑定，修改服务/模型/范围会撤销外发授权。请勿在聊天、公开仓库或公开部署的该页面中填入长期密钥或真实敏感健康资料。

浏览器调用受服务端 CORS、TLS、网络与参数兼容影响。请求失败会明确报错，绝不悄悄切回演示答案假装成功。不要关闭浏览器安全、使用未知公开代理或将密钥提交到仓库。原生版使用 Keychain 与专用网络适配器，详见 PRD。

## 文件结构

- `docs/watch_you_PRD.md` / `.docx`：完整需求，28 章，含 AI 设置、输入输出契约、自动调度与验收。
- `docs/CODEX_HANDOFF.md`：分阶段原生开发任务与证据要求。
- `prototype/index.html`：可直接打开的单文件原型。
- `prototype/*.js` / `styles.css` / `shell.html`：可编辑源码；`build.py` 重新打包。
- `schemas/`：简化原型 AI 输出 Schema、配置与证据示例，不含凭据。
- `tests/`：实际执行的单元与浏览器测试、结果和限制说明。
- `assets/`：本版合成数据界面截图。
- `CHANGELOG.md`：版本变化。

## 重建与测试

```bash
python3 prototype/build.py
node tests/core.test.cjs
node tests/ai-core.test.cjs
python3 -m pip install playwright
# 本测试使用已安装 Chromium，可通过 CHROMIUM_BIN 指定可执行文件。
CHROMIUM_BIN=/path/to/chromium python3 tests/browser_test.py
```

浏览器测试拦截所有模型请求到测试响应；不会使用真实服务和密钥。当前执行环境阻止 file:// 导航，采用 `set_content` 与内存存储适配器，**没有验证浏览器重启后的真实 localStorage 持久化**。完整记录见 `tests/TEST_REPORT.md`。

## 原生实施边界

AI 自动推断并不等于已经能可靠判定用户的真实情绪。原生实现需要质量门控、来源溯源、混杂因素处理、个性化评估与弃答。数据不足时保留未知；可选反馈用于纠正，不是每日强制输入。AI 不能自行改变健康数据、目标、提醒或诊疗行为。

原生建议 SwiftUI + HealthKit + Keychain + 本地存储 + WatchConnectivity，在同一工作区组织手机与手表 target。先实测个人签名、系统能力与通信，再扩展界面。后台调度、耗电、重签保留数据及真实模型兼容都仍需验证，不以本浏览器测试代替。

本仓库不含用户凭据，也未替用户选择公开代码许可证。第三方代码候选需在实际引入前逐项审计。
